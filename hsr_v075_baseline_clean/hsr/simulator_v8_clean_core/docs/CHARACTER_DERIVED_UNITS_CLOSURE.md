## 一次性实施约束

先沿整条链确认下列契约，再修改共享生产者。同根缺口和兄弟消费者一起收口，不只修最后一个
失败断言；实现中按这些边界自查一次后再冻结。

1. **定义与身份**：主人、属性提供者、实际攻击者/治疗者、行动控制者和受益者分别取正式字段。
   不默认全部等于 owner；区分派生定义与实例，创建来源、所属构筑与许可必须一致。
   普通 payload/trace 只能传输与审计，不能重建或授权瞬时事实。
2. **构筑与属性**：实际选中技能/行迹/星魂决定参数和有效等级，不使用编译默认等级 15。
   生命上限消费已有 `current_max_hp` 权威；生命/攻击/速度继承及例外遵循来源。出生快照与
   后续实时同步分别规定，不擅自统一为实时或全锁面板。缺策略时不回退等级 1/父全属性。
3. **出生与后续**：出生模板、动态值、启动、`OnServantCreate`/`OnBattleEventCreate` 及关系索引
   同事务有序且仅一次；后续任务的 ParamEntity 是本次新实例。未知子任务仍阻断，不能丢弃。
   每次能力调用使用稳定 invocation 身份，不随事件索引变化漂移实例作用域。
4. **合法动作与时机**：可选/自动/指令行动按来源区分；公开查询、目标查询、资源计划与提交
   共用正式准入。复用已有队列、插入窗口和终结通知，不手工拼 dequeue；普通行动、联合行动
   不重复推进 AV、开启回合、扣点或回能。不能用伪造公开选择启动不该可选的自动动作。
5. **联合与嵌套**：每段保留自己的攻击者、属性源、目标、倍率、削韧、RNG 与结算身份。
   父事实不能原样冒充子行动许可；需要继承的上下文通过正式类型化、作用域受限的路径传入。
   本包实际用到的注册事件根/并行缺口归共同生产者补齐，不全局放宽 action fact 校验。
6. **目标与归属变化**：可被攻击/治疗/选中的种类、团队人数、主从关系与胜负归属来自规则，
   被动倒计时的中立/不可选模板不能直接用于可行动忆灵或伙伴。合法 owner 变化同时更新关系、
   属性同步及后续行动归属；不默认等于销毁重建。兄弟主人/单位不能借用彼此动态值或许可。
7. **完整生命周期**：到期、自耗、确认死亡、主人状态变化、替换与再次创建逐项按实际来源
   区分；limbo 不当作确认死亡。结束时清理对应关系、目标引用、动态值/ledger、状态/光环与
   待执行队列；不能误删兄弟条目，也不能把未知 Revivable 分支当正常取消。再创建新实例
   不继承旧实例计数、状态、目标或待执行动作；阵型位置满足正式相对顺序且不重复。
8. **原子性与审计**：准入完整后才产生副作用；出生后续、联合后段或晚期 finish 失败时状态、
   队列与 RNG 按事务边界回滚。审计由实际写和原生生产者触发，不由可删除标签选择；预期来自
   RuleBook 的完整定义/计划，不能只比较两份被审副本。应有原生结算缺失、改名、错生产者或
   正确重关联后的身份/数值篡改必须拒绝；合法旁系形状必须保留。

不创建新平台或大规模框架重构；现有类型缺少实际必要字段才扩展。公共接口/归档可能不兼容时
先明确兼容要求，不自行加旧输入适配；无新依赖/环境、无 submodule 更新、无角色名/ID 分支。

测试按风险选取，复用现有检查，避免为每个字段扩成负例矩阵。必要边界至少包含：

- 同类不同主人/同实例重召唤的身份与属性隔离；实际参数变化影响对应子单位，兄弟不变。
